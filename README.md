# TugasKu - PWA Pencatat Tugas Kuliah
React + Vite + Tailwind + vite-plugin-pwa. CRUD tugas (localStorage), bisa di-install & offline.

    npm install
    npm run dev       # pengembangan
    npm run build     # produksi
    npm run preview   # tes hasil build + PWA

Ganti identitas di `src/data/profile.js`.
